Buy Best displayed its live catalog and responded to a milk search. Its source link now uses the [renamed repository](https://github.com/pranshudhiman45-bot/BuyBest-Grocery-MERN-E-Commerce-App). Screenshots are real browser captures, not generated project mockups.
- **Ryora limits:** reviewed `Testing-Project/ryora/backend/src/providers/local-video.provider.ts` returns `/demo/sample.mp4`. `services/prompt.service.ts` includes optional Gemini enhancement and a local fallback. The public site title says Kyora while its body says Ryora. No new account, paid generation or authenticated API workflow was exercised. Source implementation is distinguished from deployed behavior in the case study.
- **Services and technologies:** all nine service categories match the brief. React, Next.js, TypeScript, Tailwind, Node.js, Express, MongoDB/Mongoose, Git/GitHub, REST APIs and deployment integrations have evidence in this portfolio or the reviewed Ryora/Buy Best source. Additional languages, databases, infrastructure tools and advanced AI specialisms were not inferred from a suggested list.
- **Contact:** 26 integration tests passed using a temporary real MongoDB instance and mocked Resend HTTP responses. Coverage includes persistence before sending, validation, oversized data, honeypot, concurrent rate limits, Reply-To, HTML escaping, provider failure, safe logs, new service options and malicious query keys. Browser success/error UX used controlled API responses and sent no email. Live delivery is **not verified**.
- **Footer:** local links, service fragment targets, email href and absence of bare `#` placeholders checked. `#top` and `#main-content` are intentional working anchors. No social profile or booking destination was invented.
- **SEO:** page-specific title/description/canonical/Open Graph paths checked, social images respond, structured data identifies Pranshu, admin is noindex, and sitemap/robots respond. Production-origin correctness remains configuration-dependent.
- **Mobile/themes:** nine routes × two themes × three widths (1440, 375 and 320 pixels): 54 page checks, with screenshots at desktop and 375 pixels. No horizontal overflow, missing heading, broken portfolio image, invisible main content, or uncaught browser error found. Reviewed representative desktop and mobile screenshots.
